# Flutter - Software Research

## 1. Introduction

Flutter is an open-source UI software
development kit created by Google.

It allows developers to build applications
for multiple platforms using a single codebase.

## 2. Developer

Google

## 3. Programming Language

Dart

## 4. Supported Platforms

- Android
- iOS
- Web
- Windows
- macOS
- Linux

## 5. Main Features

- Cross-platform development
- Hot Reload
- Customizable Widgets
- High Performance
- Single Codebase

## 6. Software License

BSD 3-Clause License.

## 7. Main Purpose

Flutter is designed to develop
beautiful and responsive user interfaces.
